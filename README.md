# Inbox Agent – Outlook-paneel (DFSG)

Statisch taakvenster voor de Outlook-invoegtoepassing "Inbox Agent". Bevat geen gegevens of sleutels:
de API-configuratie (Power Automate-URL's) wordt eenmalig per gebruiker in Outlook ingevoerd en in de
roaming-instellingen van de mailbox bewaard. Alle data staat in SharePoint en Business Central.
